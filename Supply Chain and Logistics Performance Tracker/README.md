# Supply Chain & Logistics Performance Tracker

**Portfolio Track:** Data Analysis  
**Author:** OGHENEOCHUKO EMMANUEL OGIDIAGBA

## Overview

An end-to-end supply-chain analytics project built around **40,000 deterministic synthetic shipment records covering 2022–2024**.

The project examines delivery performance, carrier and route patterns, cold-chain exposure, customs holds, SLA penalties, and scenario-based financial exposure.

**Pipeline:** Data generation → validation → descriptive analytics → scorecards/risk segmentation → scenario analysis → visual reporting

## Analytical Scope

### Data quality
- Schema and integrity validation
- Missing-value handling
- Duplicate detection
- Recalculation of Delay_Days and On_Time from transit values
- Deterministic regeneration with seed 42
- Anonymization of shipment identifiers and analyst labels

### Carrier performance
Carrier scorecards use an explicit comparative weighting: 40% on-time rate, 30% normalized inverse average delay, and 30% normalized inverse penalty rate.

Only carriers with at least 100 shipments receive a comparative score. The weighting is a portfolio assumption, not a universal industry standard.

### Cold-chain analysis
Perishables and Pharma are treated as cold-chain-sensitive cargo. The project reports delay patterns, route and mode exposure, customs-hold patterns, delayed cargo value, and scenario exposure at 10%, 20%, 35%, and 50%.

These are modeled exposure scenarios, not observed spoilage losses, realized savings, or causal estimates.

### Delay analysis
Recurring delay patterns are examined by carrier, mode, cargo type, route, and month. The project uses delay patterns/hotspots rather than claiming causal root causes.

## Outputs

Running the pipeline generates key_metrics.json, executive_summary.txt, carrier_scorecard.txt, three PNG visualizations, and an anonymized shipment dataset.

The raw shipment dataset is regenerated by src/main.py so a fresh checkout remains reproducible.

## Run Locally

    python -m pip install -r requirements.txt
    python src/main.py

Run regression tests with:

    pytest -q

Generate only the deterministic dataset with:

    python src/generate_data.py

## Validation

The regression suite checks generated schema and delay integrity, absence of a hard-coded target-savings metric, carrier minimum-sample eligibility, scenario assumptions, reporting and visualization interfaces, zero delay for on-time shipments, anonymization of unrecognized client values, and all-missing categorical handling.

GitHub Actions validates the project when Project 2 files change.

## Limitations

1. Shipment data are synthetic rather than observed company data.
2. Carrier score weights are analyst-defined assumptions.
3. Scenario exposure requires domain validation before operational use.
4. Descriptive associations do not establish causality.
5. This is an analytical portfolio prototype, not a production logistics control system.
